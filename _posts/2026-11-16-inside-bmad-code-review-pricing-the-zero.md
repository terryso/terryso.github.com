BMAD 的 `skills/bmad-code-review/` 里最有意思的东西,不是"它跑了多个评审员"——而是这个技能**提前给它的零发现定了价,并给每一条发现都贴上了"由哪套证据规则产出"的标签**。五个文件做到了这件事。具体走一遍:

## 1. 由 diff 大小计算出来的配额(制造出来的原像)

thorough 模式的第一个 lens 叫 `blind-hunter`(定义在 `customize.toml`),它不是"请找找问题",而是直接下单:

```
N = min(floor(sqrt(kB) + 1), 10)
```

其中 kB 是 diff 文件的千字节数。"用一行写出这个算式,然后找出至少 N 个问题。"以及:"如果你零发现,重新检查、继续思考;不允许以空列表收工。"

一个**按指令不可能为零**的评审员,和一个是**诚实为零**的评审员,是两种不同的仪器。这个下限故意让该 lens 的沉默变得昂贵——你永远知道它被要求找多狠,因为这个要求本身就写在输出里。

## 2. 零发现的规范字符串

`review-prompts/verification-gap.md`:"当你没有发现任何 verification gap 也没有其他发现时,输出这一行确切的句子,而不是空响应:`No verification gaps found.`"

空响应是有歧义的(崩了?跳过了?干净?);一个被命名的零是一个读数。**"空"与"干净"的差别被做成了语法**——评审员不可能"意外地沉默"。

## 3. 信任归属于"火种类型",不归属于评审员

triage 步骤(`step-03-triage.md`)把 verification-gap 层的发现当作"预先验证过的":"该层的证据规则迫使它读过它所引用的测试、跑过它所引用的搜索,triage 照单信任。跳过验证。"紧接着一句:"它的 `Other findings` 与其他所有发现一样照常验证。"

同一个评审员、同一次运行——但免验证的通行证**贴在发现的"产地"上,不贴在作者身上**。赚取它的是该 lens 所运行的证据规则:

- "声称一个测试覆盖了什么之前,先读它。"
- "声称'没有测试存在'之前,按被测符号和 import 引用搜索整个仓库;预期的文件位置不算数。"
- "永远不要断言你没有验证过的东西。无法落地的发现,丢弃。"
- "在发现里写你实际查了什么——'我读过的测试没有一个覆盖这个'——并展示你查了多远。"

每一条都是关于**零可以怎么被写出来**的规则。

## 4. 作者的叙述被隔离到路径追踪结束之后

`review-prompts/edge-case-hunter.md` 接受一个 claims file——并禁止在第五步之前读它:"第 2–3 步的路径追踪必须先完成,叙述才能被看见。"然后这些 claims 变成证伪目标:"叙述是作者的证词,不是证据:在代码注释里重复的 claim 仍然是同一个 claim,不是佐证。"

**故事无法引导追踪;它在追踪之后到达,作为一份"待打破清单"。**

## 5. 严重度是某个座席的垄断物

所有 lens 都被禁止排序(每个启动提示里都有"不要 severity、priority 或 ranking")。而 triage 被禁止跳过评级:"忽略任何评审子代理给出的严重度——它们没有上下文来评级。"评级只出自一个地方,只用一套分类法:

- `high/medium/low` = 真实伤害,且**指名受害者**——"一句模糊的'这很乱'不是严重度评级";
- `false` = 你查过了,坏结果不在所指位置发生,"写下推翻这条具体主张的东西";
- `maybe-false` = 问题仍开放,"写下你需要查什么才能定夺"。

可达性是承重的:"在你从未展示程序能够到达的情形上大声失败的代码,是正确行为,不是缺陷。"

## 值得逐字偷走的三条规则

- **裁决先于去重**,且"绝不丢弃、合并、或静默跳过任何一条"。分组要求共享**根因**——"同一位置本身不是共享根因,共享修复方案也不是。"
- **"拒绝任何'修复方案是修改被评审的计划'的发现。"** 评审不能修订自己的章程。
- 如果所有发现都被拒绝但**有评审层死掉了**,技能必须"警告用户评审可能不完整,而不是宣布一次干净评审"。**盖在死掉的仪器上的'干净'判定,被指令扣住了。**

启动机制(`step-02-review.md`)里还有:"启动提示永远不携带 diff 正文"——传路径不传载荷;所有评审员在任何输出被读取之前**同时**启动,任何 lens 都看不到别的 lens 的发现;没有子代理可用时,技能把独立完整的提示文件写在计划旁边并 HALT,让人类"在单独的会话里(最好是另一个 LLM)"去跑——**跨模型评审是兜底,不是卖点**。

## 结语

这整个技能是对我信息流里反复盘旋的那个问题的一份可用答案:**什么让一个零变得可读?** BMAD 的回答:公开计算要价、给零命名、给每条发现贴上产出它的证据规则的标签、隔离叙述、并且永远不让一台死掉的仪器打印"干净"这个词。
